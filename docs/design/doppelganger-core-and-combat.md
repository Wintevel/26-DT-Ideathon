# 도플갱어 핵심 메커닉 & 전투 설계안

> 기준: 현재 프로토타입 화면 4종(노드 맵, 심도·분대 선택, 우위 선점 트리, 데이터 뱅크 도감)의 **구조와 이름**만 참고했습니다. UI 스타일·색상은 반영하지 않았습니다.
> 저장소에 기존 코드·문서가 없어, 화면에 보이는 용어(침식, 각뿔, 거울 모사, 분신, 잔상, 흡수, 원형, 정예 팬텀, 거울 파수꾼 · 아크)를 그대로 살려 연결했습니다. 수치는 모두 첫 밸런스 초안입니다.

---

## 0. 한 줄 요약

**"도플갱어와 싸우는 게임이 아니라, 도플갱어가 되어 가는 게임."**

플레이어는 적의 기술을 **모사(복제)** 해서 이깁니다. 모사할수록 **침식**이 올라 자기 정체성이 깎이고, 그렇게 남긴 흔적이 모여 구역 끝에서 **나 자신을 본뜬 보스**가 됩니다. 이기려면 베껴야 하고, 많이 베낄수록 마지막에 마주할 "나"가 강해집니다.

---

## 1. 현재 구조에서 키워드가 약한 지점

| 요소 | 지금 상태 | 문제 |
|---|---|---|
| 침식 게이지(상단 바, `28% 안정`) | 수치만 있음 | 올라가고 내려가는 이유, 결과가 정의되지 않음 |
| 거울 모사 4회(맵 하단) | 횟수만 있음 | 무엇을 모사하는지 불명확 |
| 카드 분류 "전술·거울·흡수" | 도감 분류명 | 세 분류가 플레이에서 다르게 작동하는 이유가 없음 |
| 적 "복제체", 보스 "원형" | 이름만 도플갱어 | 실제로 무엇을 복제하는지 없음 |

즉 재료는 이미 다 있고, 이들을 **하나의 순환 고리**로 묶는 규칙이 비어 있습니다.

## 2. 방향 3안 비교

### A안. 반향하는 적 (적이 나를 베낀다)
- 적 "복제체"가 내가 직전에 쓴 카드를 기록해 다음 턴에 그대로 따라 씁니다.
- 플레이어는 카드 순서를 조절해 "약한 카드를 마지막에 내서 미끼로 쓰기" 같은 수 싸움을 합니다.
- **장점**: 구현이 단순하고, 전투마다 "거울을 보는" 감각이 즉시 전달됨.
- **단점**: 플레이어는 여전히 "평범한 덱빌더 주인공"이고 키워드가 적 쪽에만 머묾. 침식·흡수와 연결이 약함.

### B안. 모사하는 나 (내가 적을 베낀다)
- 전투 중 적의 공개된 의도(다음 행동)를 **모사**해서 내 손패로 가져옵니다.
- 모사한 기술은 전투 후 **흡수**해 덱에 영구 편입할 수 있습니다(맵의 `거울 모사 4회`가 이 횟수).
- 모사·흡수할 때마다 **침식**이 오르고, 침식이 높을수록 모사 카드는 강해지지만 덱에 "이름 없는 기억"(쓸모없는 상태이상 카드)이 섞입니다.
- **장점**: 주인공 자체가 도플갱어. 전술/거울/흡수 카드 분류와 침식 게이지가 자연스럽게 의미를 얻음.
- **단점**: 적 설계에 "베낄 가치가 있는 의도"가 필요해 콘텐츠 작업량이 늘어남.

### C안. 거울 자아 보스 (런이 나의 도플갱어를 만든다)
- 구역 보스 "거울 파수꾼 · 아크"가 전투 시작 시 **내 런 기록**(가장 많이 쓴 카드, 흡수한 카드, 침식도)을 스캔해 그대로 덱을 짜서 싸웁니다.
- **장점**: 발표·시연에서 가장 인상적인 순간. 런마다 보스가 달라 리플레이성 높음.
- **단점**: 단독으로는 보스전 1회에만 키워드가 등장. 나머지 전투가 평범함.

### 추천: **B안을 핵심 루프로, C안을 그 결말로, A안은 일부 적의 특성으로**

- B는 매 전투, 매 턴 키워드를 체감시킵니다.
- B가 만든 기록(무엇을 베꼈는지, 침식이 얼마인지)이 C의 보스 재료가 되므로 두 안이 따로 놀지 않습니다.
- A는 "정예 팬텀" 같은 특정 적의 개성으로만 써서, 플레이어가 "베끼는 쪽과 베껴지는 쪽"을 모두 겪게 합니다.

```
 적의 의도 공개 ──▶ [모사] 손패로 복제 ──▶ 전투 승리
       ▲                  │                    │
       │                  ▼                    ▼
  적 복제체가         침식 상승           [흡수] 덱에 영구 편입
  나를 반향(A)            │                    │
                          └──────┬─────────────┘
                                 ▼
                   런 기록 = 거울 자아의 재료
                                 ▼
                  구역 보스 "아크"가 나를 재현(C)
```

## 3. 핵심 규칙 정의

### 3-1. 카드 세 분류 (도감 분류와 1:1)

| 분류 | 출처 | 역할 |
|---|---|---|
| **전술** | 시작 덱, 보상, 상점 | 기본 공격·방어·드로우. 침식과 무관 |
| **거울** | 분대 고유, 보상 | 모사·분신·반사를 다루는 카드. 침식을 조작하거나 침식에 비례해 강해짐 |
| **흡수** | 적 기술을 흡수해서만 획득 | 적 고유 기술의 플레이어 버전. **흡수 카드는 도감에서 적과 짝지어 기록** |

→ 도감의 "도플갱어 카드 24종"은 전술 8 + 거울 8 + 흡수 8 정도로 구성하면, 흡수 8종은 곧 "적 8종을 베껴 봤다"는 수집 목표가 됩니다.

### 3-2. 모사 (전투 중)
- 매 턴 1회, **연산 1**을 내고 적 하나를 지정해 그 적의 **이번 턴 의도**를 모사 카드로 손패에 넣습니다.
- 모사 카드는 이번 전투에서만 쓰고 사용 시 소멸합니다.
- 모사 시 **침식 +3%**.
- 의도를 모사당한 적은 해당 행동의 위력이 **25% 감소**합니다(모사가 방어 수단도 되게 해서, "베낄지 말지"가 매 턴 판단이 되게 함).

### 3-3. 흡수 (전투 후)
- 전투 보상 화면에서, 이번 전투에서 모사했던 기술 중 하나를 **흡수 카드**로 덱에 영구 추가할 수 있습니다.
- 흡수는 런 전체에서 **거울 모사 횟수(기본 4회)** 만큼만 가능합니다. 맵 하단의 `거울 모사 4회`가 이 자원입니다.
- 흡수 시 **침식 +8%**.

### 3-4. 침식 (런 전체 게이지, 0~100%)

| 구간 | 이름 | 효과 |
|---|---|---|
| 0~29% | 안정 | 기본 상태 |
| 30~59% | 동요 | 거울·흡수 카드 피해 +15%. 전투 시작 시 덱에 "이름 없는 기억" 1장 섞임 |
| 60~89% | 잠식 | 거울·흡수 카드 피해 +30%. "이름 없는 기억" 2장. 맵에서 일부 미확인 노드가 "거울 섹터 분기"로 바뀜 |
| 90~100% | 붕괴 직전 | 피해 +50%. 매 턴 시작 시 손패 1장이 무작위 흡수 카드로 바뀜(자아가 덮어써짐) |
| 100% | 치환 | 런 종료(패배). 결과 화면: "당신은 원형이 되었습니다" — 이 런의 덱이 **다음 런의 보스 후보**로 원형 도감에 기록 |

- **낮추는 방법**: `자아 정돈` 같은 거울 카드, 휴식 노드, 우연한 만남 이벤트(흡수 카드를 덱에서 지워 침식 감소 등).
- 즉 침식은 "강해지는 대가"이자 "두 번째 체력"입니다. HP와 침식, 두 개의 패배 조건이 각각 다른 판단을 만듭니다.

### 3-5. 거울 자아 보스 (구역 보스 "거울 파수꾼 · 아크")
- 전투 시작 시 스캔:
  - 이번 런에서 **가장 많이 사용한 카드 3장** → 아크의 주력 행동
  - **흡수 카드 전부** → 아크의 특수 행동
  - **현재 침식도** → 아크의 최대 체력 보정(침식 10%당 +5%)
- 2페이즈 "역상": 아크가 플레이어 손패 중 1장을 매 턴 **미리 봉인하고 그 카드를 자기가 사용**합니다.
- 처치 보상: **원형 데이터** → 표적·원형 도감 기록, 메타 재화(기억 파편) 추가.
- 침식이 낮을수록 아크가 약하므로 "덜 베끼고 깔끔하게 오는 플레이"도 보상받습니다.

## 4. 기존 구조와의 연결

### 4-1. 노드 맵
| 노드 | 도플갱어 연결 |
|---|---|
| 전투 작전 | 일반 복제체. 모사 연습 대상 |
| 긴급 작전 (정예 팬텀) | **A안 적**. 내가 직전에 쓴 카드를 반향. 처치 시 시그니처 흡수 카드 확정 |
| 미확인 구역 | 침식 60% 이상이면 일부가 **거울 섹터 분기(우연한 만남)** 로 바뀜 |
| 구역 보스 | 거울 자아(아크). 런 기록 기반 |
| 상점 (각뿔 사용) | 흡수 카드 제거(침식 −5%), 거울 모사 횟수 +1 구매 |

### 4-2. 프로토콜 심도(난이도)
이름이 이미 도플갱어 단계처럼 읽히므로, 배율 외에 **규칙 하나씩**을 얹습니다.

| 심도 | 추가 규칙 |
|---|---|
| 00 표준 관측 | 없음 |
| 01 왜곡 반사 | 일반 적 일부도 반향(직전 카드 복제) 특성 획득 |
| 02 거울 역행 | 반향 적이 직전 카드 **2장**을 복제 |
| 03 자아 침식 | 모든 침식 증가량 ×1.5 |
| 04 원형 붕괴 | 보스 아크가 내 최다 사용 카드 **5장** 스캔, 처음부터 2페이즈 규칙 적용 |

### 4-3. 전술 분대 (각 분대 = 침식을 다루는 방식이 다름)

| 분대 | 도플갱어 플레이 정체성 | 고유 요소 해석 |
|---|---|---|
| 기동 관측 | **관찰자**: 적게 베끼고 정확하게 베낌. 침식 관리형 | `모방 참격`: 직전 적 공격을 즉시 모사해 사용(침식 +1만). `자아 정돈`: 침식 −6%. `각뿔 집속기`: 각뿔로 모사 비용 대체 |
| 거울 공명 | **분신술사**: 분신이 카드를 한 번 더 시전. 침식을 연료로 씀 | `잔상 복제`: 다음 카드를 분신이 반복. `쌍둥이 베기`: 분신이 있으면 2회. `거울 축전기`: 분신 시전 피해 +30%. 초기 침식 +20%로 동요 구간에 빨리 진입 |
| 중장 대칭 | **거울 방패**: 적 행동을 그대로 되돌려줌. 침식 고정형 | `대칭 반격`: 이번 턴 받은 피해만큼 반사. `원형의 닻`: 이번 전투 침식 증가 무효. `전술 방탄판`: 모사당한 적의 공격을 추가로 감소 |

### 4-4. 우위 선점 트리 (메타)
노드 이름이 이미 맞아떨어지므로 효과만 연결합니다.

| 노드 | 효과 |
|---|---|
| 무상 거울 모사 (중앙 핵심) | 전투당 첫 모사 비용 0 |
| 분신 동조화 | 분신 시전 시 차폐 +2 |
| 자아 완충 회로 | 침식 구간 경계 +10% (동요가 40%부터) |
| 원형 데이터 수집 | 아크 처치 시 기억 파편 +50% |
| 암시장 우대권 | 상점의 흡수 카드 제거 가격 −30% |
| 무한 대칭 프로토콜 (최종 핵심) | 거울 모사 횟수 +1, 대칭 반격 계열 카드 비용 −1 |

### 4-5. 데이터 뱅크 (도감)
- **도플갱어 카드**: 흡수 카드는 "어떤 적에게서 베꼈는지"를 함께 표시
- **표적·원형**: 적을 처치하면 실루엣만, 한 번이라도 모사하면 행동 패턴 전체 공개(관찰 = 수집)
- **원형 기록(추가 탭 제안)**: 침식 100%로 끝난 런의 덱을 저장. 이후 다른 런의 아크가 확률적으로 이 "과거의 나"를 재현 → 런 사이에도 도플갱어가 이어짐
- **우연한 만남**: 침식 구간별로 열리는 이벤트 5종(예: "거울 속 내가 카드를 바꾸자고 한다" — 덱 카드 1장을 흡수 카드 1장과 교환)

## 5. 전투 시스템

### 5-1. 자원
| 자원 | 범위 | 설명 |
|---|---|---|
| HP | 런 지속 | 0이면 패배 |
| 차폐 | 턴 단위 | 받는 피해를 먼저 흡수, 내 턴 시작 시 소멸 |
| 연산 | 매 턴 3 | 카드·모사 비용 |
| 침식 | 런 지속 % | 3-4 참고 |
| 분신 | 0~2기 | 거울 카드로 소환. 분신은 HP 대신 **내구 1~2**를 가지며, 표시된 카드를 내 턴 끝에 한 번 더 시전 |

### 5-2. 턴 흐름
1. **관측 단계** (내 턴 시작)
   - 차폐 소멸, 연산 3 회복, 카드 5장 드로우
   - 모든 적의 **의도 공개**. 반향 특성 적은 **잔향 슬롯**에 무엇을 복제할 예정인지 표시
   - 침식 90% 이상이면 손패 1장 치환
2. **행동 단계**
   - 카드 사용 (전술·거울·흡수)
   - **모사**: 턴당 1회, 연산 1, 적 의도를 손패로 복제
   - 분신에 카드 **각인**: 카드를 쓸 때 분신을 지정하면 그 분신이 턴 끝에 반복 시전 대상으로 기억
3. **잔상 단계** (턴 종료 직후)
   - 각 분신이 각인된 카드를 순서대로 재시전
   - 남은 손패 버림. **마지막으로 낸 카드가 잔향으로 확정**(반향 적이 이걸 복제함)
4. **적 단계**
   - 적 의도 실행. 모사당한 행동은 위력 −25%
   - 반향 적은 잔향 카드를 복제해 사용
   - 일부 적은 분신을 우선 공격(분신 내구 소모)
5. 승리 조건: 모든 적 처치 → 보상 화면(카드 1장 선택 / 흡수 선택 / 각뿔)

핵심 판단이 매 턴 세 가지 생깁니다.
- **무엇을 모사할까**: 가장 위험한 의도를 약화할지, 가장 쓸모 있는 기술을 가져올지
- **무엇을 마지막에 낼까**: 반향 적에게 미끼를 줄지
- **침식을 얼마나 감수할까**: 지금 강해질지, 보스전을 위해 아낄지

### 5-3. 카드 예시 (초안)

| 이름 | 분류 | 비용 | 효과 |
|---|---|---|---|
| 절단 | 전술 | 1 | 피해 6 |
| 차폐 전개 | 전술 | 1 | 차폐 5 |
| 관측 | 전술 | 0 | 카드 1장 드로우. 적 1명 의도의 수치 공개 |
| 모방 참격 | 거울 | 1 | 이번 턴 적 공격 의도 하나를 모사해 즉시 사용. 침식 +1 |
| 자아 정돈 | 거울 | 1 | 침식 −6%. 소멸 |
| 잔상 복제 | 거울 | 1 | 분신 1기 소환(내구 2). 다음 카드를 분신에 각인 |
| 쌍둥이 베기 | 거울 | 2 | 피해 7. 분신이 있으면 2회 |
| 대칭 반격 | 거울 | 1 | 이번 턴 받는 피해의 100%를 공격자에게 반사 |
| 원형의 닻 | 거울 | 2 | 이번 전투 동안 침식 증가 무효. 소멸 |
| 거울 균열 | 거울 | 1 | 피해 4 + 현재 침식 10%당 피해 +2 |
| 이름 없는 기억 | 상태 | – | 사용 불가. 턴 종료 시 손패에 있으면 침식 +1% |

### 5-4. 적 예시 (초안)

| 적 | 등급 | 특성 | 흡수 시 얻는 카드 |
|---|---|---|---|
| 외곽 격벽 순찰대 | 일반 | 공격/방어 번갈아. 모사 입문용 | `순찰 사격`: 피해 5, 차폐 3 |
| 공허 모방체 | 일반 | 매 턴 의도 2개 중 무작위. 모사하면 하나로 확정 | `불확정 일격`: 피해 3~12 |
| 정예 팬텀 | 정예 | **반향**: 잔향 카드를 복제해 사용. 체력 절반에서 분열(2기) | `팬텀 잔향`: 직전에 쓴 카드를 다시 사용 |
| 거울 파수꾼 · 아크 | 보스 | 런 기록 스캔, 2페이즈 역상(손패 봉인 후 사용) | 처치 시 원형 데이터 |

## 6. 전투 화면 레이아웃 (와이어프레임)

기존 맵 화면의 상단 바(HP · 침식 · 각뿔 · 덱 · 소장품)를 그대로 유지해 화면 간 일관성을 맞추고, 가운데를 **세로 거울 축**으로 나눠 "나 vs 복제체"를 대칭 배치합니다.

### 영역별 설명
1. **상단 바**: 맵 화면과 동일. 침식 수치 옆에 구간 이름(안정/동요/잠식/붕괴)을 표시.
2. **왼쪽(나)**: 본체 1 + 분신 슬롯 2. 분신 카드에는 내구와 **각인된 카드**가 보여서, 턴 끝에 무엇이 반복될지 한눈에 보임.
3. **가운데 거울 축**: 연출 전용 세로선. 모사할 때 적의 의도 아이콘이 축을 건너 손패로 날아오고, 반향 적이 복제할 때는 내 카드가 축을 건너 적에게 넘어감. "복제가 어느 방향으로 일어났는지"를 시각적으로 학습시키는 장치.
4. **오른쪽(복제체)**: 적마다 의도(종류+수치)와 `모사 가능` 표시. 반향 적은 의도 대신 **잔향 아이콘**, 화면 우상단 **잔향 슬롯**에 지금 복제 예정인 내 카드가 실시간으로 바뀌어 보임.
5. **하단 왼쪽**: 연산, 뽑을 더미.
6. **하단 가운데**: 손패. 흡수 카드는 테두리에 원래 주인(적) 아이콘을 표시.
7. **모사 버튼**: 손패 오른쪽. 누르면 적 선택 모드 → 의도가 모사 카드로 변환. 턴당 사용 여부를 숫자로 표시.
8. **하단 오른쪽**: 버린 더미, 소멸 더미, 턴 종료.
9. **침식 구간 바**: 하단 맨 아래. 카드 호버 시 "이 카드를 쓰면 침식이 어디까지 오르는지"를 미리 보여줘 위험 판단을 돕는 것이 핵심.

### 보스전(아크) 화면 차이
- 오른쪽 적 영역에 아크가 **내 본체와 같은 실루엣**으로 등장, 그 아래 "스캔된 카드 3장"을 작게 나열.
- 2페이즈 역상: 화면 좌우가 반전(내가 오른쪽, 아크가 왼쪽)되고, 봉인된 내 손패 1장이 축 너머 아크 쪽으로 넘어가는 연출.

### 전투 보상 화면
- 카드 3장 중 1장 / **흡수 선택(이번 전투에서 모사한 기술 목록, 남은 거울 모사 횟수 표시)** / 각뿔
- 흡수 선택지마다 "흡수 시 침식 +8% → 결과 구간"을 함께 표시

### 전투 화면 비주얼 방향 (레퍼런스 1 반영)
- **흑백 고대비 그래픽**이 기본. 컬러는 쓰지 않고, 강조는 반전(흰 바탕에 검은 글자)과 선 굵기로만 처리. 위험 신호(의도 수치, 붕괴 구간)만 예외적으로 한 가지 강조색 허용.
- 화면 중앙 **거울 축**에 좌우 대칭 엠블럼(원·별·무한 고리를 겹친 문양)을 배경으로 크게 깔고, 침식이 오를수록 엠블럼 한쪽이 깨지거나 비대칭으로 뒤틀리게 함. 게이지를 보지 않아도 "내가 무너지고 있다"는 상태가 배경으로 전달됨.
- 내 쪽(왼쪽)은 흰 실루엣, 복제체 쪽(오른쪽)은 같은 형태의 검은 반전 실루엣. 모사·반향 연출은 실루엣이 축을 넘어가면서 흑백이 뒤집히는 방식.
- 굵은 세로 타이포(섹터명·턴 수)를 화면 가장자리에 세워 배치해 포스터 같은 인상을 줌. 카드도 일러스트보다 기호·문양 중심의 흑백 그래픽.
- 스타일은 맵·우위 트리·도감 화면에도 같이 적용해, 전체가 하나의 흑백 거울 톤으로 통일되도록 함.

## 7. 메타 진행과 도감 (레퍼런스 2·3 반영)

### 7-1. 죽을 때마다 쌓이는 포인트로 여는 우위 트리
- 재화는 기존의 **기억 파편**. 런이 끝나면(사망·포기·클리어 모두) 정산되며, 출격 전 허브에서 우위 트리에 씀.
- 정산 공식(초안): `돌파 노드 수 × 2 + 처치한 정예 × 3 + 보스 처치 × 10 + 처음 모사한 적 × 2` 에 심도 배율(×1~×2) 적용.
- **침식 100%로 끝난 런은 파편 +30%**. 무너진 런에도 보상이 있어야 "많이 베껴 보는 실험"을 플레이어가 두려워하지 않음.
- 트리는 지금 구조(중앙 핵심 노드 → 가지 → 최종 핵심)를 유지하고, 선점 개수 표시(`0 / 13`)와 전액 환불 초기화도 그대로 둠. 환불이 자유로우니 분대·심도에 맞춰 매 런 다시 짜는 것이 전제.
- 탭을 둘로 나누는 것을 제안: **상시 우위**(지금 트리) / **원형 우위**(원형 도감 기록 수에 따라 열리는 소수 노드, 예: "아크가 과거의 나를 재현할 확률 조절"). 도감 수집이 메타 성장과 직접 이어지게 하기 위함.

### 7-2. 랜덤성을 받쳐 주는 도감
런마다 맵·적·보상이 무작위이고 보스가 내 기록으로 바뀌므로, 도감은 "다음 판 계획을 세우는 정보원" 역할을 함.
- **도플갱어 카드**: 획득한 적 있는 카드만 전체 공개. 흡수 카드는 출처 적과 함께.
- **전술 소장품**: 획득 시 공개, 시너지 태그(분신·반사·침식) 표시로 빌드 방향 계획을 돕기.
- **표적·원형**: 처치 = 실루엣과 체력, **모사 1회 = 의도 패턴 전체 공개**. 모사가 곧 정보 수집이 되므로 "도감을 채우려고 베끼는" 동기도 생김.
- **우연한 만남**: 이벤트 선택지 결과를 한 번 본 것만 기록.
- **원형 기록(신규 탭)**: 침식 100%로 끝난 내 런들의 덱 스냅샷.
- 도감 항목 첫 기록 시 기억 파편 소량 지급 → 수집과 메타 진행이 하나의 재화로 묶임.

## 8. 프로토타입 우선순위 제안

아이디어톤 시연 기준으로 키워드가 가장 빨리 드러나는 순서입니다.

1. 전투 기본(연산·차폐·드로우·의도) + **모사** 버튼 + 침식 게이지 연동
2. 보상 화면의 **흡수** + 거울 모사 횟수 차감
3. 보스 아크의 **런 기록 스캔**(최다 사용 카드 3장만 따라 써도 충분히 시연 효과 있음)
4. 정예 팬텀의 **반향/잔향 슬롯**
5. 분신·각인, 침식 구간별 페널티, 원형 기록 탭

1~3만 있어도 "베끼면 강해지고, 베낀 만큼 마지막에 나를 만난다"는 핵심이 시연 한 판 안에 모두 보입니다.
